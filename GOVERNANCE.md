# Governance

## Current phase

Open UPP is maintainer-led and in the research/design phase. The initial maintainer coordinates repository administration, triage, and project direction.

## Decision making

- Small documentation corrections may be merged directly by maintainers.
- Protocol and security changes require written rationale and review.
- Significant changes should be discussed in an issue or design proposal before implementation.
- Decisions should record alternatives, trade-offs, and compatibility implications.
- Community feedback is welcome; maintainers remain responsible for final decisions until a broader governance model is adopted.

## Future governance

As the contributor community grows, the project may adopt documented roles, release management, a technical steering process, and a formal proposal process. Governance changes should be discussed publicly and recorded here.
