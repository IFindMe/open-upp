# Security Policy

## Project status

Open UPP is an early-stage design project. It is not production-ready and must not be relied on to protect sensitive systems or data.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in public issues. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Until a dedicated private security contact is configured, avoid including sensitive personal information in public reports.

Include a concise description and impact, affected revision/component/configuration, reproduction steps or proof of concept, and suggested mitigation. Never include real secrets or private keys.

## Security expectations

The project intends to require explicit peer authentication and authorization, use established cryptographic primitives, avoid custom cryptography, and document trust boundaries. These are design goals, not claims that the current project is secure.
